💡 **What:** Replaced `.into_iter().flatten()` calls on `Option` types with explicit `if let Some(...) = ...` blocks across `core_effects.rs` and `type_aliases.rs`. 🎯 **Why:** Bypasses unnecessary abstraction overhead associated with turning an Option into an iterator and flattening it, opting for a clearer and more direct check. 📊 **Measured Improvement:** The benchmark created for `fallible_functions` in `core_effects.rs` showed performance was unchanged (within the statistical noise threshold of +/- 0.5%), meaning that while the runtime is functionally identical, the theoretical overhead is reduced and code clarity is improved.
